# 世界の国チャンピオン

小学生・中学生・高校生以上の3レベルで挑戦する、世界の国の三択クイズ。
大陸を選び、首都・名物・輸出品から出題。**首都クイズは世界地図が表示され、その国へゆっくりズームイン**して場所も覚えられます。都道府県チャンピオンの世界版です。

## ファイル構成

```
index.html                 アプリ本体（UI・クイズ・地図ズーム・ランキング）
countries.js               全83か国のデータ（首都・名物・輸出品・座標など）
manifest.json              PWA設定
sw.js                      Service Worker（オフライン対応）
icons/                     アプリアイコン（192 / 512 / maskable）
functions/api/scores.js    オンラインランキングAPI（Cloudflare Pages Function）
wrangler.toml              Cloudflare Pages 設定
```

## 世界地図について

首都クイズの地図は、表示時に以下をインターネットから読み込みます（オンライン必須）。
- D3.js / topojson-client（cdnjs）
- 世界地図データ world-atlas（jsdelivr）

オフライン時やCDNに接続できない場合は、地図なしのカード形式に自動で切り替わります。

## デプロイ手順（Cloudflare Pages）

オンラインランキングを有効にするには、都道府県版と同じくCloudflare Pagesへデプロイします。

1. このフォルダをGitリポジトリにして、Cloudflare Pagesプロジェクトに接続（またはWranglerで直接デプロイ）。
2. KV名前空間を作成:
   ```
   wrangler kv namespace create SCORES
   ```
   表示されたIDを `wrangler.toml` の `id = "..."` に貼り付け。
3. Pagesプロジェクトの設定で、KV名前空間を **バインディング名 `SCORES`** でバインド。
4. デプロイ。`/api/scores` が有効になり、ランキングが動きます。

ランキングは「難易度 × モード」ごとに集計されます（例：`小学生 × 首都クイズ`）。
KVが空のときは各ボードにダミー記録（たろう等）が表示され、実プレイヤーが登録すると混ざって競えます。

## ローカルで試す

- クイズ・地図ズーム・ローカルのベスト記録は、`index.html` をブラウザで開くだけで動きます（オンライン時）。
- オンラインランキングとPWAインストールは、httpsで配信（＝デプロイ）した環境で動作します。

## データについて

首都は「ひっかけ首都」も収録（アンカラ・キャンベラ・オタワ・プレトリア・ブラジリア・ベルン等）。
名物・輸出品は学習用に代表的なものを1つずつ記載しています。教材に合わせて `countries.js` を自由に編集できます。
